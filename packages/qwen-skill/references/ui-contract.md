# 界面契约

本文件定义眼镜端任务列表、详情、结果与产物的呈现规则。语音模板见
`references/speech-contract.md`。

## 任务列表（UiTool.list）

- 调用顺序固定：先 `list_tasks`（`limit=5`），再 `UiTool.list`。列表最多五行。
- 每行只包含：短号、截断后的标题、中文本地化状态、阶段、连接新鲜度、未读标记、
  相对更新时间。顺序按 `updated_at` 倒序，并保持 MCP 返回的先后关系。
- 行内不得出现原始 `job_id`、UUID、请求正文或事件负载。
- 用户说“第几个”时，只映射**紧邻上一次列表**中的序号；序号超出或列表已变化时
  重新列出，不做跨列表推断。

## 任务详情（UiTool.all_text）

- 详情固定调用 `get_task`，不猜测状态。
- 正文顺序：仓库显示名、短号、状态、阶段、连接新鲜度、最近更新、最多五条事件摘要、
  待审批标题、终态摘要。
- 正文按最多五行打包：仓库/短号、状态/阶段、连接/最近更新、进度、待审批/结论。
- 正文最多 600 个字符。接近上限时先丢弃最旧的事件摘要，再缩短阶段、待审批标题、
  终态摘要与仓库显示名；短号与状态永不截断。
- 没有事件时显示“暂无进度详情”，不得编造进度、百分比或预计完成时间。
- 事件摘要必须脱敏：去掉 UUID、链接、凭据样式字符串与百分比，单条摘要一行。

## 结果与产物

- 文本结果使用 `UiTool.all_text`，包含摘要、相对改动文件名、测试摘要与产物元数据。
- 图片结果只有在同时满足以下条件时使用 `UiTool.pic_and_text`：
  HTTPS 链接、恰好一张图片、受支持的图片类型（PNG/JPEG/WebP）、过期时间在将来。
- 任一条件不满足（多图、本地路径、过期、非 HTTPS、未知类型）时回退为
  `UiTool.all_text` 文本元数据，并说明“图片不可用”的原因；不得把不可用链接写进正文。
- 产物元数据只写类型、数量与有效期，不写本地路径或凭据。

## 边界

- 正文最多 600 字符，语音最多 120 字符，列表最多 5 行。
- 不使用百分比、原始日志、堆栈、链接或私密会话标识。
- 不展示推送相关承诺；数据只在用户询问时读取。
