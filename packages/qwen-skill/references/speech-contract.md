# 语音契约

语音使用中文普通话（zh-CN），由固定模板生成，不做自由改写。所有模板都必须
包含短号与状态，且不超过 120 个字符。

## 模板

| 场景 | 模板 |
|---|---|
| 创建成功 | 任务 QH-7M2P 已创建，等待 Mac 接单 |
| 已接单 | 任务 QH-7M2P Mac 已接单 |
| 执行中 | 任务 QH-7M2P 正在执行，阶段：运行测试 |
| 等待审批 | 任务 QH-7M2P 等待你的批准 |
| 取消中 | 任务 QH-7M2P 正在取消 |
| 已完成 | 任务 QH-7M2P 已完成，结果已显示 |
| 执行失败 | 任务 QH-7M2P 执行失败 |
| 已取消 | 任务 QH-7M2P 已取消 |
| 已过期 | 任务 QH-7M2P 已过期 |
| 连接正常 | 连接正常 |
| 连接不稳定 | 连接不稳定 |
| 连接中断 | 连接中断，正在协调 |
| 列表结果 | 任务列表已显示，共五个 |

## 约束

- 只朗读短号、状态、阶段与连接状态；不朗读文件列表、原始错误、审批指纹、链接或
  任何事件负载。
- 不推测进度，不朗读百分比，不承诺由服务端自行发起通知或常驻监听。
- 列表只播报总数（最多五条），例如“任务列表已显示，共五个”；详情只朗读第一条最相关结果，其余由界面展示。
- 语音文本长度以 Unicode 字符计数，最多 120；超出时先省略阶段，再省略连接状态。
