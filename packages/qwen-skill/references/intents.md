# 意图路由

本文件定义眼镜任务台的单意图路由规则，是 SKILL.md 的细则。

## 路由表

| 路由 | 意图 | 读取/变更 | 工具序列 |
|---|---|---|---|
| create | 创建开发任务 | 变更 | `submit_task` |
| list | 列出任务 | 读取 | `list_tasks`，然后 `UiTool.list` |
| inspect | 查看单个任务 | 读取 | `get_task`，然后 `UiTool.all_text` |
| cancel | 取消任务 | 变更 | `cancel_task` |
| list_approvals | 待审批列表 | 读取 | `list_pending_approvals`，然后 `UiTool.list` |
| decide_approval | 批准或拒绝 | 变更 | `decide_approval` |
| result | 读取结果 | 读取 | `get_task_result`，然后 `UiTool.pic_and_text` |
| rtc | 实时语音通话 | 受特性开关控制 | `rtc_mode` 为 false 时不提供 |

## 单意图规则

- 一个回合只执行一个变更意图。读取可以跟在变更后面展示回执，但不得追加第二个变更。
- 用户在一个回合里要求两个变更时：执行第一个明确请求，然后用一句话询问是否在新
  回合执行第二个。不得把两个变更合并进一次工具调用。
- 意图不明确时先问一个澄清问题，不猜测参数。
- 参数缺失（仓库、模式、短号）时先补齐再调用，不编造默认值。

## 参数提取

- 仓库：从 `config/repositories.json` 解析，规则见 `references/tool-contract.md`。
- 模式：用户说“只读”“先别改代码”时使用 `read_only`，否则 `normal`。
- 短号：`QH-` 加四位大写字母数字；短号不是 UUID，也不是仓库标识。
- 请求正文：保持用户原意，最长 4000 字节，不附加未确认的指令。

## 歧义与拒绝

- 仓库零候选或多候选：列出配置中的候选并等待确认，不调用 `submit_task`。
- 用户给出路径（含 `/`、`~`、`..` 或盘符）：说明路径不能作为仓库标识，请其
  提供配置中的名称或编号。
- 用户要求的能力未开启（例如实时语音）：直接说明未开启，不模拟成功。

## 失败处理

- 校验或策略拒绝：说明原因与需要用户补充的信息，不重试。
- 幂等冲突：说明该请求编号已被使用，请用户确认是否要新建任务。
- 连接器离线：说明任务已排队并保留同一个请求编号，恢复后再提交。
- 传输超时或临时不可用：最多重试一次，载荷逐字节相同。
