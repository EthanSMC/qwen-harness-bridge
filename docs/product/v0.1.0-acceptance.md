## Evidence procedure

1. Commit the implementation and this evidence schema.
2. Run local application gates and independent review.
3. Push the Issue #7 branch and open a PR containing `Closes #7`.
4. Run the dedicated GitHub Docker gate against the exact implementation SHA.
5. Add an evidence-only commit containing the exact run URL and observations below.
6. Rerun all current-head gates and obtain fresh independent review before merge.

This two-phase procedure avoids a self-referential commit hash: the implementation SHA is immutable evidence input, while the later evidence-only commit records its results.
